# Endringer av vedtektene til Java Brukerforening i Norge

Ønsket endring skal lages som en PR for å holde styre på hva som endres. Disse vil da bli stemt over på generalforsamlingen.

# Endringer av vedtektene til JavaBin Økonomi AS

Det er styret i Java Brukerforening i Norge som er generalforsamling for JavaBin Økonomi AS. Endringer i vedtektene til ASet gjennomføres av styret på ordinær eller ekstraordinær generalforsamling. De nye vedtektene lastes opp på Altinn. Når de er godkjente oppdaterer man pdf-filen her med de nye vedktektene.
